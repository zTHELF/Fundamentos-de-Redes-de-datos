El comando net user <usuario> <nueva_contraseña> es una instrucción directa de modificación, por lo que no despliega ningún campo de datos en la consola.

Al ejecutarlo correctamente, la pantalla solo muestra el mensaje de estado de la operación:

Respuesta en pantalla: El comando se completó correctamente. (o The command completed successfully.).

Campos que se actualizan internamente
Aunque la consola no imprima una tabla en el instante, esta orden modifica y actualiza los siguientes campos dentro de la ficha del usuario en el sistema:

Campo modificado,                                       Cambio que ocurre
Password last set (Contraseña última modificada),       Se actualiza automáticamente con la fecha y hora exactas en las que ejecutaste el cambio.
Password changeable (Contraseña cambiable),             "Se restablece a la fecha y hora actuales, indicando desde cuándo se puede volver a modificar."

(La nueva contraseña no se muestra en ningún campo por motivos de seguridad. Para ver la actualización del campo de fecha, debes consultar de nuevo la cuenta con net user <usuario>).

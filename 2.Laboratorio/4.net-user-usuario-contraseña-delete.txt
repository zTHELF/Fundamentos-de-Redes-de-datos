El comando net user <usuario> <contraseña> /delete no es válido en la sintaxis de Windows. Al incluir la contraseña junto con el parámetro /delete, el sistema arrojará un error de sintaxis y no mostrará ningún campo de datos.

La forma correcta para eliminar una cuenta es sin incluir la contraseña:

net user <usuario> /delete

Al ejecutarlo correctamente, tampoco se genera una tabla de campos; la consola únicamente responde con un mensaje de estado:

Respuesta del sistema: El comando se completó correctamente. (confirma que la cuenta de usuario especificada fue eliminada de la base de datos local SAM del sistema).

Si ejecutas la versión incorrecta con la contraseña: Muestra un error como La sintaxis del comando es incorrecta. o Sintaxis no válida.

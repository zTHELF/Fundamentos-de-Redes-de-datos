El comando net user * no es una orden independiente, sino una variante que se utiliza al final de un comando de asignación para solicitar una contraseña oculta por teclado.

Al incluir el asterisco (*), la consola te pide que escribas la clave sin que se muestren los caracteres en pantalla (por privacidad y seguridad).

Comportamiento según cómo se combine
1. Para cambiar la contraseña de un usuario existente (net user <usuario> *)

Qué hace: Le cambia la clave al usuario pidiéndotela en pantalla de forma oculta (evita que la contraseña quede escrita en texto plano en el historial del CMD).

Campos que muestra: Solicita en la consola:

Type a password for the user: (Escriba una contraseña para el usuario)

Retype the password to confirm: (Vuelva a escribir la contraseña para confirmar)

Campo interno que actualiza: Modifica Password last set (Contraseña última modificada) con la fecha y hora actuales.

2. Para crear un usuario nuevo (net user <usuario> * /add)

Qué hace: Crea la cuenta y te pide asignar la contraseña de forma oculta en ese instante.

Campos que muestra: Pide ingresar y confirmar la clave en pantalla.

Campos internos que asigna: Asigna la clave y habilita la cuenta asignándola por defecto al grupo *Users.

Ejemplo de lo que se ve en pantalla
C:\Users\Administrator>net user Guest *
Type a password for the user:
Retype the password to confirm:

The command completed successfully.

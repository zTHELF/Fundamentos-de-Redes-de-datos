El comando net user <usuario> /passwordchg:no es una instrucción de seguridad que sirve para bloquear o impedir que el usuario pueda cambiar su propia contraseña en el sistema.

¿Qué campos muestra en la consola al ejecutarlo?
Al ser un comando de modificación, no muestra una tabla con campos de datos. Solo despliega el mensaje de confirmación habitual:

Respuesta en pantalla: El comando se completó correctamente. (o The command completed successfully.).

Campo que actualiza internamente en la ficha del usuario
Al aplicarlo, modifica el permiso de gestión de clave en la ficha del perfil:

Campo modificado
User may change password (El usuario puede cambiar la contraseña)

Cambio que ocurre
Cambia su valor a No, quitándole el permiso al usuario para modificar su clave desde el menú de Windows o la combinación Ctrl + Alt + Supr.
